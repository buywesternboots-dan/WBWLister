GOAL / FLOW
1. Dan (an authenticated BootLister admin) imports a seller's current marketplace listings with BootLister's EXISTING import tools (unchanged).
2. BootLister creates or connects that seller's WBW profile (POST action "seller") using the seller's actual login email, display name, location and an explicit "authorized" confirmation checkbox the admin ticks.
3. BootLister sends selected listings + photos to that seller's WBW inventory (POST action "import"), one listing per request.
4. Dan chooses per transfer: save as draft (publish:false) or request publication (publish:true, requires shipping_type + shipping_cost).
